# Ball Projection

ビリヤードのボール配置を仮想台 (真上視点) に並べて、保存・共有する HTML アプリ。
有名な試合の配置を取り込んで自分で再現する、といった使い方を想定している。
オプションで、カメラ画像 / 写真から Gemini でボールを読み取ったり、配置を実際の台のカメラ映像に重ねて表示したりできる。

## 起動

ES Modules とカメラ (secure context) を使うため、HTTP サーバー経由で開く。

```sh
python3 -m http.server 8000
# http://localhost:8000/
```

ビルド不要、依存なし。スマホのカメラを使う場合は HTTPS が必要なので GitHub Pages で公開する。

## GitHub Pages で公開

Settings → Pages → Source を「Deploy from a branch」、ブランチ `main` / `/ (root)` にする。
`main` に push すると `https://<user>.github.io/<repo>/` に反映される (`.nojekyll` で Jekyll 処理を無効化)。

## 使い方

### 配置タブ (メイン)

1. タイトルを入力し、必要なら「メモ」に試合名・選手・出典などを書く。
2. 台の下のボールをタップしてから台の上をタップすると配置。ドラッグで移動 (ドラッグ中はボールの位置に縦横の点線を表示)、台の外へドラッグすると削除。「元に戻す」(Ctrl+Z) で取り消し。台の下に「元に戻す」「URLで共有」「保存」を置き、台・パレット・ボタンが 1 画面に収まるよう台の大きさを調整する。台の上でもボール以外の場所はスワイプでスクロールできる。
3. 置いたボールはパレットで薄く表示される (同じ番号は 1 個まで)。台サイズ、ポイント線 / 半ポイント線 (既定でどちらも表示) を切り替えられる。
4. 画面が縦長 (スマホ縦持ち) のときは台を縦向きに表示する。座標データは向きに関係なく同じ。
5. 「URLで共有」でタイトル・メモ付きの共有 URL を作る (スマホは共有シート、PC はクリップボード)。開いた側は配置・台サイズ・タイトル・メモが読み込まれる。
   形式: `?v=1&title=<タイトル>&memo=<メモ>&table=9ft|<長辺>x<短辺>&balls=<番号>_<x>_<y>.<番号>_<x>_<y>…` (mm、番号 0=手球 / -1=不明)
6. 「保存」でブラウザに名前を付けて保存し、一覧から「読込」「削除」。「保存データを書き出し」でまとめて JSON に書き出し、「JSON読込」で取り込む (1 件分の JSON も読込可)。

### カメラタブ (オプション)

1. 「設定」で Gemini API キーとモデル (既定 `gemini-3.8-flash`) を入力。「一覧を取得」で API キーで使えるモデルを候補に出せる。
2. 「カメラ開始」または「画像を開く」。
3. 台の4隅を指定する。
   - 手動: 「角を指定」→ プレイエリアの角 (クッションのノーズ線の延長交点) を4点クリック。ドラッグで微調整。
   - 自動: 「AIで角検出」。
   - 1→2 の辺が長辺になる。向きが違えば「角の割当を回転」。
4. 4隅を指定すると、配置タブの配置がカメラ画像に重ねて表示される。実際の台にボールを並べて再現するときの目安にできる。
5. 「ボール検出」で写っているボールを読み取り、配置を置き換える (角が未設定なら角検出も行う)。カメラ固定なら「連続検出」で一定間隔ごとに再検出。

## 仕組み

- 4隅の対応から射影変換 H (画像 ⇔ 台座標 mm) を計算 (`js/homography.js`)。
- Gemini に台の外接矩形を切り出した画像を送り、各ボールの `box_2d` と番号を JSON (responseSchema) で受け取る (`js/gemini.js`)。
- 番号は、検出した各ボールを元画像から拡大して切り出し、もう一度 Gemini に判定させる (候補3つを確率付き)。1回目の番号と合算し、確率の高い順に重複しないよう割り当てる (`js/numbers.js`)。確率 0.5 未満や不明は一覧で要確認表示。設定で無効化可。
- バウンディングボックス中心を H で台座標に変換。クッションのノーズ高さ (≒36mm) はボール中心高さ (28.6mm) に近いので、ノーズ線で角を取れば視差の誤差は小さい。
- 逆変換で仮想台 (枠・ダイヤモンド線・ボール) をカメラ画像に重ねる。逆方向にカメラ画像を真上視点へ補正して仮想台の背景にも表示できる (`js/table.js`)。

## 注意

- 設定 (API キー含む)・作業中の配置・名前付き配置はブラウザの IndexedDB (`ball-projection`) に保存する (`js/storage.js`)。API キーはブラウザから `generativelanguage.googleapis.com` に直接送る。空欄で保存するとキーを削除。
- 台サイズはプリセット (9ft/8ft/7ft) かカスタム。ボールはポケットビリヤード (手球 + 1〜15) 前提。
- 配置データは JSON ファイルでも保存・読込可能 (座標単位 mm、原点は角1)。
